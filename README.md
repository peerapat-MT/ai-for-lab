# AI-Assisted Web App Development for Medical Laboratory

สไลด์ประกอบ Workshop — สร้าง Web App สำหรับงานห้องปฏิบัติการ ด้วย Google Sheets + Google Apps Script + AI Coding Agent (Claude Code / Codex) + Visual Studio Code

**เปิดสไลด์:** https://peerapat-mt.github.io/ai-for-lab/

| ไฟล์ | รายละเอียด |
|---|---|
| `index.html` | สไลด์ 41 แผ่น เปิดในเบราว์เซอร์ได้ทันที |
| `Lab_Reagent_Database.xlsx` | ข้อมูลตัวอย่าง (Synthetic) สำหรับฝึกทำ Lab Reagent Inventory Web App |

## วิธีใช้
- `→` / `Space` ถัดไป · `←` ย้อนกลับ · `F` เต็มจอ · `O` ภาพรวมทุกสไลด์
- `/` หรือ `Ctrl+K` ค้นหาสไลด์และลิงก์ดาวน์โหลด
- `M` สลับการเคลื่อนไหวแบบลด / แบบเต็ม
- ปุ่ม "คัดลอก" ใต้ Prompt และคำสั่ง ใช้คัดลอกไปวางใน Claude Code / Codex / Terminal
- บนมือถือ หมุนเป็นแนวนอนเพื่อดูสไลด์ได้ชัดขึ้น

ข้อมูลในไฟล์ตัวอย่างเป็นข้อมูลสมมติทั้งหมด ไม่มีข้อมูลผู้ป่วย
